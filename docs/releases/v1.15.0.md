# TensorNote v1.15.0

知识库智能体现在可以使用与应用一致的 Project Experiment 规范。随 Release 分发的 Skill 增加完整选择规则、安全与平台审查清单、最小/完整 Manifest 模板，并扩展独立校验器：检查环境继承、Preset、步骤依赖图、结构化参数、产物和只读下载声明。
