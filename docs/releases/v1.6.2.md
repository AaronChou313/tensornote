# TensorNote v1.6.2

中文（默认） · [English](v1.6.2.en.md)

修复长文阅读和双栏编辑体验，增加可移植的自定义首页与公开仓库分享入口。在线 Web、本地 Web 和桌面版包含同一批核心修订，保持 Workspace Schema v1 兼容。

## 本次变化

- 宽屏阅读时右侧 Outline 保持可见；长目录独立滚动，避免随正文消失或压缩目录文字。窄屏可通过上下文栏按钮打开目录。
- 修复没有 Frontmatter 分类的中文文件夹显示为“未分类”的问题。空附件目录显示文件夹图标，图片仍通过 Markdown 引用展示。
- 双栏预览拥有独立滚动区，默认按标题锚点双向同步；标题之间近似插值，无标题时按整体进度对齐。可关闭同步分别浏览，源码字号也略有增大。
- 根目录 `README.md` 可作为 Overview 正文，支持相对图片和库内笔记链接；`OVERVIEW.md` 存在时优先使用。顶部简介使用 `workspace.description`（若设置 `publishing.description` 则优先使用后者）。无需通过应用编辑这些文件。
- 分享窗口增加默认分支的“知识库最新内容链接”，保留固定 Revision 链接。公开知识库可直接使用 `https://aaronchou313.github.io/tensornote/#/open/github/OWNER/REPO`。分享不会自动信任远程代码。
- 中英文使用说明与同版本 Agent Skill 发行资产同步更新。

## 下载与开始使用

- [在线 Web](https://aaronchou313.github.io/tensornote/)：直接打开示例或公开 GitHub 知识库。
- 本地 Web：下载 `TensorNote-local-web-1.6.2.tar.gz`，安装 Node.js 22+，解压后运行 `node start.mjs`，无需前端构建。
- Desktop：下载匹配系统/架构的安装包。先保存现有未保存笔记，再退出旧版并打开新版。知识库无需迁移。
- Agent：下载 `TensorNote-agent-skill-1.6.2.tar.gz`，将完整目录与目标知识库交给智能体。
- [中文使用说明](../zh-CN/USER_GUIDE.md) · [GitHub Release](https://github.com/AaronChou313/tensornote/releases/tag/v1.6.2)

## 验证与限制

本地 179 项 JavaScript 测试、3 项性能测试、Lint、TypeScript、生产依赖审计、Static Web 边界检查，以及 Rust fmt/clippy 和 14 项测试通过。macOS Apple Silicon 实测中文目录、README 图片与链接、长文大纲及双向同步；公开仓库直达与分享入口在 Web 实测。发行资产还需通过 Tag 流水线与下载验签，公开状态以 Release 为准。

GitHub 社区包没有 Apple Developer ID 公证或 Windows 受信发布者签名，首次打开可能提示未识别的开发者。Updater 仍强制验签，下载可使用 `SHA256SUMS` 与 `release-manifest.json` 核对。Windows/Linux/Intel macOS 构建成功不等于干净机器安装实测。

Git 仍是本地 Status/Diff/Stage/Commit/History；Push/Pull/Clone/分支管理使用外部 Git 客户端。本地 Web 按需运行 Git Bridge，桌面版无需 Bridge。在线计算仍需兼容的 HTTPS Jupyter/CORS/WebSocket；公共 Binder 容量与完整执行、跨版本自动升级保留为验证债务。参见[发行矩阵](../RELEASE_MATRIX.md)。不要移动已公开 Tag；回归通过新的 Patch 修复。
