# TensorNote v0.6.0 — Extension Platform

v0.6.0 建立官方/本地插件平台，让 TensorNote 的工作台、Markdown 和 Provider 边界可以按统一契约扩展。

## Extension API v1

- 新增 Manifest 验证、最低版本检查和贡献 id 命名空间约束。
- 新增 `load → activate → deactivate → dispose` 生命周期；停用时自动撤销扩展注册的贡献。
- 支持注册 Command、声明式 View、Sidebar Item、Markdown Processor、CodeMirror Editor Extension、Settings、Status Bar Item、Workspace Provider 和 Compute Provider。
- 扩展命令复用现有 `CommandRegistry`，自动进入 `Ctrl/Cmd + P` Command Palette。

## Permissions and local loading

- 支持 `workspace:read`、`workspace:write`、`network`、`compute`、`secret` 权限。
- API 调用同时检查 Manifest 声明和用户授权；写入、网络、计算和 Secret 权限作为高风险能力默认不选中。
- 本地加载先解析 Manifest，确认权限后才导入 JS/MJS 入口。
- 扩展管理器明确提示：浏览器同源 JavaScript 不是安全沙箱，只能加载可信脚本。
- v0.6.0 仅支持官方和本地插件，不提供公共在线市场。

## First-party extension and UI

- 内置 `Focus Mode` 官方扩展，实际使用 Command、View、Sidebar、Setting 和 Status Bar API。
- 新增淡绿色、圆润、明暗主题兼容的扩展管理器、权限确认卡、扩展状态栏和声明式 View Dialog。
- Markdown Renderer 和 CodeMirror 编辑器会消费当前活动扩展贡献。

## Verification

- 新增 Manifest 兼容性、权限边界、命名空间、生命周期和贡献清理测试。
- 全部 `44` 个单元测试通过，并通过 ESLint、TypeScript 和 Vite production build。
