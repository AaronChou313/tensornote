# TensorNote v0.9.3 — Focused Pane Workspace

源码阶段日期：2026-08-31

v0.9.3 完成工作台的焦点和展示区重构。本阶段会提交并推送源码，但不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 独立阅读编辑区

- 每个 Pane 自己包含历史、标签、固定与关闭操作栏，操作栏和内容在同一个 Pane 模块内对齐。
- 每个 Pane 有独立滚动容器；拆分后滚动、焦点和内容高度不再相互干扰。
- 右侧上下文栏始终面向当前焦点 Pane 的笔记；Python Lab 入口从右栏移除，避免同一实验出现两套尺度不一致的面板。

## 可靠性与简化

- Lab 每次打开都重建对应实例，点击笔记中的 Lab 卡片能够稳定显示当前笔记的实验。
- 设置由右上角齿轮打开为自动保存弹窗，可由关闭按钮或遮罩退出；侧栏不再重复显示 Settings。
- Command Palette 变为无背景虚化的顶部浮层；Files、Recent Files 和 Extensions 使用统一可折叠结构。

## 验收

- 自动回归覆盖设置状态重置及重复 Lab 打开的重挂载 nonce。
- 浏览器验收覆盖神经网络笔记 Lab、设置弹窗、双 Pane 独立滚动容器、命令浮层和 Files/Extensions 折叠。
