# TensorNote v0.1.0 — Workspace Foundation

TensorNote 从单一 AI 学习笔记应用升级为通用、Markdown-first 的知识 Workspace，同时保留原有可执行学习体验。

## 新增

- `tensornote.yaml` v1 Schema 与安全默认值。
- 通用 `WorkspaceProvider`、能力声明和统一内容索引链路。
- 内置、本地目录、GitHub 公开 Repository 三种只读 Provider。
- GitHub 直达 URL：`/open/github/{owner}/{repo}?ref={branch}`。
- 最近打开 Workspace、来源标识和 Workspace 概览。
- GitHub Revision 级信任；远程代码默认禁止执行。
- 本地和远程资源图片解析。

## 设计更新

- 全站改为简约、现代、圆润、柔和的淡绿色视觉系统。
- 统一首页、侧栏、顶栏、概览、阅读页、搜索和 Python Lab 的间距与状态样式。
- 明亮和暗色主题分别提供独立代码配色，确保代码文字与背景保持清晰对比。
- 修复桌面侧栏定位、路由滚动位置和 Workspace 刷新后的回退行为。

## 安全与隐私

- 无配置 Workspace 默认不允许执行代码。
- Jupyter Token 改为仅当前浏览器会话保存，不再持久写入 Local Storage。
- GitHub 内容固定到打开时解析出的 commit SHA；Repository 更新后需要重新信任。

## 验证

- `pnpm test`
- `pnpm lint`
- `pnpm build`
- 浏览器检查浅色/深色首页、Workspace 概览、阅读页、Python Lab、GitHub 只读来源和 Revision 信任状态。
