# TensorNote v1.6.4

[中文](v1.6.4.md) · English

This patch fixes remote workspace refresh and file navigation, and removes the unfinished built-in Focus Mode. Online Web, Local Web and Desktop share these changes.

- Recent Workspaces supports removing one entry or clearing all local shortcuts without deleting workspaces or trust settings.
- Unpinned GitHub links bypass browser caches and resolve the branch's latest commit; full commit links remain immutable.
- Files preserves the real filesystem hierarchy and directory names inside `content.root`; Frontmatter `section` and `overview.md` no longer rename folders.
- Each level lists folders first and naturally sorts by real directory and file names, so `chapter2` precedes `chapter10`.
- The built-in Focus Mode and its legacy settings are removed; Extension API and local extension management remain available.

The changes passed complete checks independently: 187 tests, lint, type checks and production builds. Release CI performs version validation and all-platform packaging.

[Online Web](https://aaronchou313.github.io/tensornote/) · [User guide](../en/USER_GUIDE.md) · [All releases](https://github.com/AaronChou313/tensornote/releases)

GitHub community packages remain unnotarized by Apple Developer ID and unsigned by a trusted Windows publisher; updater signatures remain mandatory. See [v1.6.3](v1.6.3.en.md) for other boundaries.
