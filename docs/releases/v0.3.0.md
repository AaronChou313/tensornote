# TensorNote v0.3.0 — Knowledge System

TensorNote 从文件目录进入可关联的 Markdown 知识系统。所有关系仍从普通 Markdown 和 YAML Frontmatter 重建，不引入专有内容数据库。

## KnowledgeIndex

- 为每个 Workspace 统一索引 documents、headings、links、backlinks、tags 与 properties。
- 支持 Frontmatter `aliases`、`tags`、任意属性和正文 Inline Tag。
- 保存、刷新或文件操作后自动重建索引。
- 代码块内的伪链接、伪标签与伪 Heading 不会污染知识关系；代码正文仍可被全文搜索。

## Links 与嵌入

- 支持 `[[WikiLink]]`、Alias、`[[Note#Heading|Label]]` 和标准相对 Markdown 链接。
- 支持 `![[Embedded Note]]` 与 Heading Section 嵌入。
- 循环嵌入会安全降级为提示，不会导致无限渲染。
- 未解析链接会在 Knowledge 页面集中列出。

## Knowledge UI

- 笔记页面新增当前笔记优先的 Local Graph。
- Links 面板显示 Tags、Backlinks、Outgoing Links 与未解析目标。
- Outline 面板覆盖 H1–H6，并可直接跳转到对应 Heading。
- 新增 Knowledge 页面，用于浏览 Tag Atlas、Property Index、关联笔记与 unresolved links。
- Sidebar、Workspace Overview 与 Topbar 均提供一致的 Knowledge 导航状态。

## Search v2

- 按 Title、Alias、Tag、Heading、Path、Property 和 Body 加权排序。
- 搜索结果显示命中字段和正文上下文。
- 保留对 Markdown 代码内容的搜索能力。

## 设计与兼容

- 延续淡绿色、现代、圆润、柔和的 TensorNote 视觉系统。
- Local Graph、知识侧栏和 Tag Atlas 在明亮与暗色主题下均使用同一语义色板。
- 不改变 `tensornote.yaml` Schema 1，也不改变 Workspace Provider 格式。
- 内置和 GitHub Workspace 继续只读，但完整支持知识索引和导航。
