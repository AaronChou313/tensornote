# TensorNote v0.8.1 — Workbench & Authoring polish

发布日期：2026-08-30

v0.8.1 是一个源码阶段里程碑，聚焦 Workbench 导航、Markdown 写作流与轻量的 Obsidian 式视觉整理。本阶段提交并推送代码，但不创建 GitHub Release 或 Tag。

## 改进

- 桌面文件侧栏在展开时只保留一个收起入口；收起后在顶部栏提供稳定的恢复展开入口。窄屏保留单一目录开关，避免重复控制。
- Workspace Overview、Knowledge、Database、Git 等视图与笔记标签、活动窗格和笔记历史分离，路由切换不会将视图误写入笔记历史。
- Workspace 卡片提供概览、刷新和切换入口；切换时检查未保存的笔记与 Lab，随后关闭 Provider、Compute 与 Git 会话并清理工作台临时状态，再返回启动页。
- Heading 1–6 现在正确处理空行、光标所在行和多行选择，格式化后将光标留在可继续输入的位置。
- Markdown 格式工具改为现有 Phosphor 图标；命令名称保留在可访问名称和悬浮提示中。
- 普通 CodeMirror 正文编辑不再显示 YAML Frontmatter。编辑与分屏模式提供可折叠的独立 Properties 面板；保存时将正文与原始 YAML 重组，并保留未知 YAML 键。
- 调整为更柔和的淡绿色、圆角、低对比层次与暗色主题兼容的工作台外观，同时收紧窄屏交互。

## 测试与发布边界

- 定向回归覆盖 YAML/正文可逆分离、未知 Frontmatter 键、空行 Heading 光标位置，以及 Workspace view 与笔记 history 分离。
- 最终候选通过全量 Vitest（64 tests）、ESLint、TypeScript 与 Vite 生产构建，以及 `git diff --check`。
- 浏览器验收覆盖桌面侧栏收起/恢复、Workspace View 与笔记路由往返、切换 Workspace、390px 移动抽屉，以及明暗主题；控制台无错误。
- 本阶段创建 Git commit 并推送 `main`，但不创建 GitHub Release 或 Tag；不包含 v0.9.0 发布工作。
