# TensorNote v2.1.0

TensorNote 2.1 completes the path from launching the app to entering a knowledge base.

## Highlights

- Redesigned the home page around recent knowledge bases and three core actions, with a compact Web/Desktop badge and guide link.
- Create local knowledge base now creates `tensornote.yaml`, `notes/`, and `assets/` under a user-selected parent and opens the result.
- Added one public read-only online entry for GitHub, GitLab, and Gitee, including optional refs and Unicode paths.
- Added separate cache lifetimes for mutable refs and immutable commits; GitHub quota errors now show the expected reset time.
- Simplified sharing to a copy-link action. Links follow the current ref by default, while revision pinning lives under More options. Legacy GitHub reader links remain compatible.
- Recent supports local and all three remote sources, individual removal, clear-all, and migration cleanup for obsolete bundled records.
- Removed AI Learning Notes, its bundled provider and content, and the automatic example fallback when no session exists.

## Security and compatibility

Remote repositories remain public and read-only, with no token, account, or private-repository support. Desktop creation accepts only an opaque authority returned after the user selects a parent directory. Workspace Schema v1, remote revision trust, future-schema read-only fallback, and the Sidecar/Jupyter boundary remain intact.

This is a release-note draft. This development task does not create a `v2.1.0` tag, GitHub Release, updater release, or Pages deployment.
