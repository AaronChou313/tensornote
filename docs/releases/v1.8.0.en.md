# TensorNote v1.8.0

Project Experiment Preview B adds safe read-only parsing and Workspace indexing.

- Parses `tensornote-experiment` fences and Manifest v1.
- Validates relative paths, environment inheritance, step DAGs, runners, presets, and input files.
- Indexes valid and invalid experiments without blocking other notes.
- Extends the Workspace validator, Skill reference, and reusable template.
- Parsing never starts processes, accesses the network, installs dependencies, or writes to the Workspace.

Existing Inline Labs, Workspace Schema v1, and Provider API v1 remain compatible.
