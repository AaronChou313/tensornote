# TensorNote v2.1.0

TensorNote 2.1 完整打通了从启动应用到进入知识库的路径。

## 主要变化

- 将首页重构为“最近打开 + 三个核心操作”的知识库入口，并加入紧凑的 Web/桌面版标识与使用说明链接。
- “新建本地知识库”现在会在用户选择的父目录中真实创建 `tensornote.yaml`、`notes/` 和 `assets/`，随后自动打开。
- 在线知识库统一支持 GitHub、GitLab 与 Gitee 的公开只读仓库、可选 Ref 和 Unicode 路径。
- 远程元数据与目录树按可变 Ref / 固定 commit 使用不同缓存周期，减少匿名 API 请求；GitHub 限额错误会显示预计恢复时间。
- 分享窗口收束为复制阅读链接，默认跟随当前 Ref；固定 revision 移入“更多选项”。旧 GitHub 阅读链接继续兼容。
- 最近打开覆盖本地和三种在线来源，可单项移除或清空，并自动清理旧的内置示例记录。
- 删除 AI Learning Notes、Bundled Provider、内置笔记资源及无 Session 时的自动示例回退。

## 安全与兼容

远程仓库保持公开只读，不新增 Token、账号或私有仓库能力。桌面创建只接受用户选择父目录后返回的不透明授权标识。Workspace Schema v1、远程 revision 信任、未来 Schema 只读降级及 Sidecar/Jupyter 边界保持不变。

本文件是发布说明草案；本开发任务不创建 `v2.1.0` Tag、GitHub Release、Updater 发布或 Pages 部署。
