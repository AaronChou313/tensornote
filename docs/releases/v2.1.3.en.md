# TensorNote v2.1.3

This release adds PDF export for the current note through the same printable document on Web and Desktop.

## Single-note PDF export

- adds an Export PDF action to the current note toolbar;
- prints a dedicated Print View without Files, tabs, toolbars, buttons, or the SidePanel;
- reuses the existing MarkdownRenderer for KaTeX, Mermaid, images, tables, callouts, and syntax-highlighted code;
- expands Derivation Sidecars in place as complete supplementary derivations;
- expands Jupyter Sidecars in place with cell titles and Python source;
- never executes Python, changes kernel state, or includes runtime outputs while exporting;
- uses white-background print styles that constrain wide media and avoid splitting math, images, tables, and short code blocks where possible.

Open a note in the browser or desktop app, select the print icon in the top toolbar, and choose Save as PDF in the system print dialog. Disable Headers and footers in the print settings if you do not want the browser-provided date, URL, and page number.

This version exports one current note only. It does not add batch or whole-workspace export. GitHub community desktop packages may still trigger an unverified-developer warning; the existing Updater signature system is unchanged.
