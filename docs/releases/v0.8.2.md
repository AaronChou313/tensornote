# TensorNote v0.8.2 — Compatibility & Migration

发布日期：2026-08-30

v0.8.2 是通向 v0.9.0 的源码阶段里程碑，建立 Workspace、浏览器设置与 Extension API 的兼容迁移边界。本阶段提交并推送代码，但不创建 GitHub Release 或 Tag。

## 改进

- Workspace Manifest 解析现在返回明确的兼容状态、源版本、目标版本与警告。
- 缺少 `schemaVersion` 的早期 Manifest 会在内存中迁移为 Schema v1，原始文件不会被自动改写。
- 高于当前支持版本的 Workspace 仍可阅读 Markdown；Session 自动关闭写入、Git 和执行，避免旧 Runtime 破坏未来格式。
- App Preferences、Recent Workspaces、Extension Grants/Settings 与 Git Bridge 设置加入持久化版本及纯函数迁移，错误类型和未知权限会被移除。
- Extension Manifest 可声明 `apiVersion`。省略时按 v1 兼容；请求未来 API 版本时给出明确错误。
- Workspace Overview 显示 Schema 迁移或兼容模式提示。

## 验证与发布边界

- 回归覆盖无版本 Manifest、未来 Schema 降级、四类设置迁移与 Extension API 版本协商。
- 阶段候选通过全量 Vitest、ESLint、TypeScript/Vite 构建和 `git diff --check`。
- 本阶段创建 Git commit 并推送 `main`，但不创建 GitHub Release 或 Tag。
