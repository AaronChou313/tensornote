# TensorNote v2.0.0

TensorNote 2.0 将产品收缩为 Web 阅读分享与 Desktop 本地创作运行两个 Host，并以 Contextual Sidecar 统一数学推导和 Jupyter 实验。

## 新增

- `derivation` 与 `jupyter` 两种 Markdown Sidecar 指令，以及统一、可调宽度的 SidePanel。
- 编辑器 Sidecar 插入器、TopBar Outline Popover、旧 `python exec` Lab 兼容适配。
- 面向智能体的 Sidecar Skill 规范、模板和 Validator 规则。

## 改变

- Workbench 同时只显示一个活动笔记；移除双 Pane、双栏预览与滚动同步。
- 正式产品只保留 Web / Desktop；浏览器开发服务器不再打包为 Local Web Edition。
- Web 面向阅读、固定 revision 分享与远程 Compute；Desktop 面向本地创作、环境管理和本机/远程 Compute。

## 移除

Command Palette/Registry、Extension Platform、Structured Database、Graph UI、Git Workspace/Git Bridge、Project Experiment，以及相关原生能力、发行资产和当前产品文档。

## 迁移

Workspace Schema v1、普通 Markdown、附件、Frontmatter、WikiLink、搜索、GitHub Provider、Compute Provider、执行授权、revision trust 和未来 Schema 只读降级继续兼容。旧 Lab 自动作为 Jupyter Sidecar 读取；新内容建议改用 `:::tensornote{...}`。Git 同步改用独立 Git 客户端。
