# TensorNote v1.13.0

Local Web 与在线版的 Project Experiment 页面现在可以通过已配置的 Jupyter 运行兼容子集。运行前，TensorNote 会在 Kernel 内验证“Jupyter Workspace 路径”及清单引用文件是否存在；映射错误会在执行脚本前停止，并给出实际检查路径。

`python` 与 `python-module` 使用 Python 标准库包装器保留 argv 边界，不调用 Shell。Notebook 可通过 `nbclient` 生成 `.tensornote-runs` 执行副本。每次运行仍要求 Workspace 执行授权、GitHub Revision 信任、路径检查和用户确认。含 `torchrun` 的预设会明确引导用户选择兼容预设或桌面版。

Jupyter 路径映射属于 Compute Profile；Git Bridge 继续只负责 Local Web 的 Git 操作，不参与实验执行。
