# TensorNote v1.13.0

Project Experiments in Local Web and Online Web can now run the supported subset through a configured Jupyter service. Before any script runs, TensorNote checks the configured Jupyter workspace path and every referenced file inside the kernel. A bad mapping stops execution and reports the checked path.

`python` and `python-module` use Python standard-library wrappers that preserve argv boundaries without invoking a shell. Notebooks can create executed copies under `.tensornote-runs` through `nbclient`. Every run still requires workspace execution permission, GitHub revision trust, a successful path check and explicit confirmation. Presets containing `torchrun` direct users to a compatible preset or Desktop.

Workspace path mapping belongs to the Compute Profile. Git Bridge remains responsible only for Local Web Git operations and is not part of experiment execution.
