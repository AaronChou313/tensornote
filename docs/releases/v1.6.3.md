# TensorNote v1.6.3

中文（默认） · [English](v1.6.3.en.md)

修复 README 内嵌 HTML 显示为源码的问题，在线 Web、本地 Web 与桌面版同步支持。

- 正常显示 HTML 横幅、居中标题、徽章和图片尺寸。
- HTML 相对图片继续通过知识库读取接口加载，无需修改 README。
- 过滤脚本、事件属性、危险链接、表单和自定义 CSS；代码块中的 HTML 仍显示为源码。
- 保持 Markdown、公式、实验卡片及 Workspace Schema v1 兼容。

已有 184 项测试、Lint、类型检查、生产构建、Static 边界检查、3 项性能测试与生产依赖审计通过；macOS App 构建成功，Happy-LLM README 已在本地 Web 实测。本次版本号更新不重复本地测试，发行流水线负责构建及发行验证。

下载匹配系统的桌面安装包，或 `TensorNote-local-web-1.6.3.tar.gz`（Node.js 22+，解压运行 `node start.mjs`）。[在线 Web](https://aaronchou313.github.io/tensornote/) · [使用说明](../zh-CN/USER_GUIDE.md)。先保存笔记并退出旧桌面版再更新，无需迁移知识库。

沿用 GitHub 社区发行方式：没有 Apple Developer ID 公证或 Windows 受信发布者签名；Updater 强制验签。其他功能边界及限制见 [v1.6.2](v1.6.2.md)。
