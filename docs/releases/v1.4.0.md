# TensorNote v1.4.0 — Publish & Read Anywhere

状态：源码阶段完成；未创建 Git Tag、GitHub Release 或签名安装包。

## 新增能力

- 分享面板可复制固定 `owner/repository@commitSHA` 的 Web 链接与 Open in TensorNote Badge，并提供 Repository、Fork、当前 revision 下载和 Desktop 打开入口。
- GitHub 打开路由支持固定笔记；未指定时使用 `publishing.defaultNote`，不存在则安全回到 Workspace Overview。
- Workspace Schema v1 增加可选 `publishing` 展示块：标题、描述、相对 Logo、Accent 与首页笔记 ID。
- Static 构建可通过四个 `VITE_TENSORNOTE_PUBLISH_*` 变量成为某个 Repository 的自动打开 Reader，不引入新的内容数据库或 Provider。
- 新增可复用 `.github/workflows/publish-workspace.yml` 与 Skill 内单文件调用模板，第三方 Repository 推送 Markdown 后即可执行校验、构建并部署 Pages。
- 新增 `pnpm validate:publication`，组合严格 Workspace 校验、License、环境声明、展示配置、完整 revision 与明显凭据文件检查。
- Desktop 注册 `tensornote://`，只接收固定 GitHub commit 的受限深链；单实例转发和未保存内容保护均已接入。

## 安全与兼容

- `publishing` 只影响展示，不包含 Token、凭据、执行授权或 Compute Profile；非法路径与颜色在 Runtime 中被丢弃，并在发布检查中失败。
- 分支仍可用于手动打开，但分享链接只能由 Provider 已解析的完整 commit 生成。
- Deep Link 不支持本地路径、Shell、命令参数或分支名，也不会自动信任远程代码。
- Static Web 构建继续不包含 Tauri、Native Workspace/Git、Local Runtime 或 Deep Link 插件实现。
- WorkspaceProvider、ComputeProvider、Executable Markdown、Extension 与 Settings/Secret v1 契约保持兼容。

## 验收门

- `pnpm check`、`pnpm test:performance`、`pnpm audit --prod --audit-level high`。
- `pnpm build:web`、`pnpm build:desktop:web`、`pnpm check:desktop` 与 `tauri build --no-bundle`。
- Skill 快速校验、Workspace 模板严格校验、内置 Workspace 校验与发布前检查。
- 真实 Static Reader：固定 revision 自动打开首页，分享弹窗显示可复现链接、来源、环境与信任状态。
- GitHub Actions Web/Container 与 macOS/Windows/Linux Desktop 编译门。
