# TensorNote v1.6.2

[中文（默认）](v1.6.2.md) · English

Improves long-note reading and split editing, and adds a portable custom homepage and public repository sharing entry point. Online Web, Local Web and Desktop include the same core changes and retain Workspace Schema v1 compatibility.

## Changes

- The Outline stays visible while reading on wide screens. Long outlines scroll independently without disappearing or compressing their text. Narrow screens retain the context sidebar button.
- Chinese folders without Frontmatter categories retain their directory names instead of becoming “Uncategorized”. Empty asset directories use folder icons; referenced images render in Markdown.
- Split preview uses independent scroll containers with bidirectional heading-based synchronization enabled by default. Positions between headings are interpolated; documents without headings use proportional progress. Synchronization can be disabled. Source text is slightly larger.
- Root `README.md` supplies the Overview body, including relative images and links to notes. `OVERVIEW.md` takes priority when present. Customize the introduction with `workspace.description` or the higher-priority `publishing.description`. These files can be edited outside TensorNote.
- Share Workspace adds a latest-content link for the default branch while retaining pinned Revision links. Open a public workspace with `https://aaronchou313.github.io/tensornote/#/open/github/OWNER/REPO`. Sharing never automatically trusts remote code.
- Chinese and English guides and the matching Agent Skill distribution are updated.

## Get started

- [Online Web](https://aaronchou313.github.io/tensornote/): open the example or a public GitHub workspace.
- Local Web: download `TensorNote-local-web-1.6.2.tar.gz`, install Node.js 22+, extract and run `node start.mjs`. No frontend build is required.
- Desktop: choose the installer for your system and architecture. Save unsaved notes before quitting the old app and opening the new one. No workspace migration is required.
- Agent: download `TensorNote-agent-skill-1.6.2.tar.gz` and provide the complete directory and target workspace to your agent.
- [English guide](../en/USER_GUIDE.md) · [GitHub Release](https://github.com/AaronChou313/tensornote/releases/tag/v1.6.2)

Public repository URLs and sharing were checked in Web. Release assets must additionally pass the tag workflow and downloaded-asset verification; consult the Release for publication status.

GitHub community packages do not have Apple Developer ID notarization or a trusted Windows publisher signature. Your OS may show an unidentified developer warning. Updater signatures remain mandatory; verify downloads with `SHA256SUMS` and `release-manifest.json`. Windows/Linux/Intel macOS builds are not clean-machine installation tests.

Git remains local Status/Diff/Stage/Commit/History. Use an external Git client for Push/Pull/Clone/branches. Local Web optionally uses Git Bridge; Desktop does not need it. Online compute requires compatible HTTPS Jupyter/CORS/WebSocket support. Full public Binder execution and cross-version automatic upgrade remain validation debts.
