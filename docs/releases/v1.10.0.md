# TensorNote v1.10.0

桌面版 Project Experiment 增加可审计的环境准备流程。实验页会检查本机 Python 与环境工具，解析预设继承的依赖文件，展示安装计划、目标位置、步骤、文件大小和 SHA-256；只有输入确认短语后才会创建隔离环境并安装依赖。

计划绑定 Workspace 授权、Experiment Manifest 和依赖文件内容。计划过期，或 Manifest、依赖文件发生变化时，应用会拒绝执行并要求重新确认。安装日志可查看、操作可取消，未完成目录会清理；设置中的运行时助手也可安全清理未被 Jupyter 使用的 TensorNote Managed Environment。
