# TensorNote v2.1.2

此版本汇集 v2.1.x 的阅读、文件身份、Sidecar 写作与排版体验改进。

## 阅读体验

- 移除旧 Knowledge Panel 留下的 286px 空列，正文使用舒适的 900px 最大宽度；
- 每篇笔记在当前 Workspace Session 中独立保存滚动位置，显式标题跳转优先；
- 收紧标题、段落、列表、代码块、公式、表格、引用、Callout 与 Mermaid 的纵向节奏；
- 在保持约 15px 正文字号和 1.72 行高的前提下，同一技术笔记单屏可见内容约增加 24%；
- 窄屏保留 16～24px 安全边距，深色模式和 Sidecar 内容保持一致。

## 文件与索引

- 路径决定文件身份，显式 Frontmatter ID 决定知识语义身份；
- 不同目录中的同名 Markdown 可以正常打开；
- Files 保持真实文件系统层级和文件名排序；
- Overview 只使用根目录 `OVERVIEW.md` 或 `README.md`。

## Sidecar 写作

- “侧栏内容”支持可视化新增、编辑和删除 Derivation 与 Jupyter Sidecar；
- 支持 Markdown 预览、Python Cell 编排、自动 ID 和格式诊断；
- Agent Skill 与 Validator 同步采用相同的 Sidecar 和文件身份规则。

本版本不改变 Desktop Updater、Apple 签名或 Windows 签名体系。GitHub 社区包仍可能显示操作系统的未认证开发者提示。
