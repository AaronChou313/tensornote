# TensorNote v0.8.4 — Distribution & Performance

发布日期：2026-08-30

v0.8.4 是通向 v0.9.0 的最后一个源码阶段里程碑，完成 Web 分发适配、可选 PWA、自托管容器与大 Workspace 性能门。本阶段提交并推送代码，但不创建 GitHub Release 或 Tag。

## 改进

- 新增 Static、Local、Self-hosted `DeploymentAdapter`，能力声明、Router 与 Git Bridge 入口随运行模式变化。
- Static Web 使用 Hash Router、可配置 Base Path、PWA Manifest、Service Worker 和 Netlify 风格 Rewrite 文件。
- 提供只手动触发的 GitHub Pages Workflow，不因代码 Push 自动发布。
- 提供 Docker、Compose 与 Nginx SPA fallback 的 Self-hosted Web Runtime。
- Workspace Provider 操作增加递归/文档并发限制，刷新可按文件指纹复用解析结果。
- Knowledge Index 预计算搜索字段并降低链接、标签构建时的数组复制。
- Jupyter Compute Provider 改为首次使用时加载，主包不再同步包含 Jupyter Client。
- 超大文件树每批渲染 200 个同级项目，仍可逐批展开。
- 新增 1,000/10,000 笔记、大 Markdown 和大 Asset 列表性能回归。

## 验证与发布边界

- `pnpm test:performance` 验证大 Workspace 数量级预算；Static build 额外验证 Base Path、Manifest 与 Service Worker 产物。
- 阶段候选通过全量 Vitest、ESLint、TypeScript/Vite 构建和 `git diff --check`。
- 本阶段创建 Git commit 并推送 `main`，但不创建 GitHub Release 或 Tag。
