# TensorNote v1.12.0

Project Experiments now cover notebooks and distributed training entry points. The Notebook runner executes through Jupyter in the managed environment and writes an executed copy under TensorNote application data, preserving the source notebook. Completed jobs can reveal that copy.

`torchrun` uses structured process, node, rank, address, port and argv fields and launches through the selected environment Python without shell strings. Desktop shows detected CPU, memory, disk, GPU and CUDA information before planning. Clear shortages require an explicit override. Long jobs show step status, recent logs, elapsed time and a keep-awake reminder.

Manifest v1 adds optional `downloads` metadata for model or dataset source, estimated size, cache path, license and SHA-256. TensorNote reviews and displays this metadata; it does not download automatically.
