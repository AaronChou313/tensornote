# TensorNote v1.17.0

本版重构环境管理和 Project Experiment 依赖准备流程。

- “计算与 Jupyter”先选择本地运行或远程运行。Desktop 本地运行提供便捷连接和手动连接；本地 Web 只提供手动连接；在线 Web 只提供远程连接。
- Desktop 会从 PATH、macOS/Linux 常见安装位置和 Windows 常见目录探测 Conda，并显示实际可执行路径；仍未找到时可手动选择 Conda 或 uv。
- 新建环境明确区分 uv、Conda 和标准 venv。Conda/uv 可创建 Python 3.11，venv 的版本严格跟随基础解释器。确认前会显示完整目标路径和安装步骤。
- 环境列表显示管理器、完整 Python 版本、路径、Jupyter 状态和 Server 所有权；TensorNote 只删除自己创建且未在使用的环境。
- Experiment 环境页会合并 Manifest 声明和工作目录中检测到的 `requirements*.txt`。用户选择目标环境后可安装单个或多个文件；计划绑定 Workspace、Manifest、文件摘要和目标环境，应用前需要输入确认短语。
- 外部环境会显示不可回滚警告。安装失败或取消时保留现有环境并报告可能的部分安装状态；新建环境失败仍清理未完成目录。

本版保持 Workspace Schema v1、Workspace Provider v1、Compute Provider v1 和 Project Experiment Manifest v1 兼容。环境与工具路径保存在设备侧，不写入知识库；Token 仍只存在当前会话。
