# TensorNote v0.9.1 — Editor Experience & Settings

源码阶段日期：2026-08-31

v0.9.1 优先处理长期写作与阅读中的编辑器、分栏和设置体验。本阶段会提交并推送源码，但不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 编辑器与 Markdown

- 常用格式动作收敛为单行图标工具栏，Heading 使用样式选择器，语言和低频动作进入下拉或溢出菜单。
- 默认编辑模式、行号和长行换行成为持久设置。
- 只隐藏与文档属性标题相同的首个 H1，后续 H1 正常显示。
- Frontmatter 继续由独立 Properties 组件维护，正文编辑器只编辑 Markdown Body。

## 独立 Pane 与 Tab

- 主、次 Pane 分别维护标签、固定状态和导航历史。
- Split Left / Right 创建空白次 Pane，不再复制当前笔记。
- 从侧栏选择的笔记进入当前活动 Pane；关闭一个标签不会联动关闭另一个 Pane。
- 双窗格采用紧凑阅读排版，窄屏只显示活动 Pane。

## Lab 可靠性

- LabDrawer 使用笔记 ID 与 Lab ID 联合定位实验，避免跨笔记同名冲突。
- 从笔记打开实验会绑定来源笔记；Scratch 写回笔记后立即打开刚保存的实验。

## 简化导航与设置

- Workspace 切换器直接放到侧栏左上角，可展开概览、刷新和切换操作；移除重复 Workspace 卡片。
- 新增 `/settings`，集中外观、编辑器、Jupyter、扩展和关于信息。
- 顶栏移除分散的主题、Kernel Profile 与扩展配置，只保留搜索、命令、Scratch 和设置。

## 验收

- 自动回归覆盖 Pane 独立状态、Heading transform、H1 渲染、Lab 回跳和设置迁移。
- 浏览器验收覆盖 Workspace 切换、空白分栏、独立双笔记、单侧关闭、LabDrawer、桌面设置页和 390px 移动布局。
