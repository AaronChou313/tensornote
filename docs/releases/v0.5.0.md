# TensorNote v0.5.0 — Workbench

v0.5.0 将 TensorNote 从单页 Reader/Editor 推进为本地优先的 Knowledge IDE 工作台。

## Workbench

- 新增多标签、固定标签、最近文件、后退/前进和主/次 Pane 拆分。
- 新增可组合的 Files/Search 左侧栏与 Properties、Outline、Backlinks、Graph、Python Lab 右侧上下文栏。
- 新增 `CommandRegistry` 与 `Ctrl/Cmd + P` Command Palette；导航、视图、计算和编辑动作从同一注册表执行。Run all 会选择活动 Pane 当前笔记的首个 Lab，LabDrawer 匹配并一次性消费 `pendingLabAction` 后调用既有 Run all；执行继续受 Workspace trust、Compute Profile 和 Session Scope 约束。
- 保留 `Ctrl/Cmd + K` 全局搜索；在 CodeMirror 编辑器内该快捷键用于插入链接。

## Markdown authoring

- 新增统一 Markdown 编辑命令与 Authoring Toolbar：段落/标题、行内格式、链接/图片、引用/Callout、列表、Python code fence、表格、分隔线和数学块。
- 工具栏、快捷键和 Command Palette 共享同一纯 transform；每个操作通过单次 CodeMirror transaction 进入 Undo 历史。
- 保持原有 Reading / Editing / Split、保存、dirty guard、外部冲突提示、资产上传、Frontmatter Properties、Knowledge 与 Compute 功能。

## 架构与文档

- 新增 `PRODUCT.md`，只记录仓库和既有产品说明能支持的事实；明确未声明商业事实。
- 增加 `docs/WORKBENCH.md`，并更新 README、Architecture、Development 和 Roadmap。
- 增加 workbench 状态与 Markdown transform 的高价值单元测试。
