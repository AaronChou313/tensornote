# TensorNote v2.0.0

TensorNote 2.0 narrows the product to a Web host for reading/sharing and a Desktop host for local authoring/execution. Contextual Sidecars now unify detailed derivations and Jupyter experiments.

## Added

- Portable `derivation` and `jupyter` directives with one resizable SidePanel.
- Sidecar authoring, a TopBar Outline popover, and a legacy `python exec` Lab adapter.
- Sidecar-aware Agent Skill guidance, templates, and deterministic validation.

## Changed

- One active note surface replaces dual panes and synchronized split preview.
- Formal distribution includes Web and Desktop only; the browser dev server is no longer a Local Web edition.
- Web focuses on reading, fixed-revision sharing, and remote compute. Desktop handles native local authoring and local/remote compute.

## Removed

Command Registry/Palette, Extension Platform, Structured Database, Graph UI, Git Workspace/Bridge, Project Experiment, and their native/release surfaces.

## Migration

Workspace Schema v1, Markdown, assets, Frontmatter, WikiLinks, search, GitHub/Compute Providers, execution permission, revision trust, and future-schema read-only fallback remain compatible. Legacy Labs open as Jupyter Sidecars. Use a dedicated Git client for synchronization.
