# TensorNote v2.1.2

This release brings together the v2.1.x improvements to reading, file identity, Sidecar authoring, and typography.

## Reading

- removes the obsolete 286px Knowledge Panel column and uses a comfortable 900px maximum note width;
- restores an independent in-session scroll position for each note, with explicit heading navigation taking priority;
- tightens the vertical rhythm of headings, paragraphs, lists, code, math, tables, quotes, callouts, and Mermaid diagrams;
- shows about 24% more content per viewport in the reference technical note while retaining an approximately 15px body size and 1.72 line height;
- preserves 16–24px safe margins on narrow screens and consistent Dark Mode and Sidecar rendering.

## Files and indexing

- uses paths for file identity and explicit Frontmatter IDs for semantic identity;
- allows Markdown files with the same filename in different directories;
- preserves the real filesystem hierarchy and filename ordering in Files;
- limits Overview selection to root `OVERVIEW.md` or `README.md`.

## Sidecar authoring

- visually creates, edits, and deletes Derivation and Jupyter Sidecars from the Sidecar menu;
- supports Markdown preview, Python Cell ordering, automatic IDs, and diagnostics;
- aligns the Agent Skill and Validator with the same Sidecar and file identity rules.

This release does not change the Desktop updater or Apple and Windows signing systems. GitHub community packages may still trigger an unverified-developer warning from the operating system.
