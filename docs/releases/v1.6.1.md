修复桌面外部链接未打开浏览器的问题，覆盖帮助、笔记参考与分享链接。`v1.6.0` 保留为未公开发行的候选 Tag；不覆盖它，社区首发使用本 Patch。

GitHub 社区发行：提供在线 Web、本地 Web 启动包、Desktop 安装资产和同版本智能体 Skill。公开时间、对应提交和附件以 [GitHub Release](https://github.com/AaronChou313/tensornote/releases/tag/v1.6.1) 为准。

## 下载后如何开始

- [在线体验](https://aaronchou313.github.io/tensornote/)：直接打开示例或公开 GitHub 知识库。
- 本地 Web：下载 `TensorNote-local-web-1.6.1.tar.gz`，安装 Node.js 22+，解压后运行 `node start.mjs`。无需安装前端依赖。
- Desktop：选择匹配系统/架构的安装包，打开本地知识库即可读写；运行实验时再使用 Jupyter 环境助手。
- Agent：下载 `TensorNote-agent-skill-1.6.1.tar.gz`，将完整 Skill 与目标知识库目录交给智能体。
- [完整中文使用说明](../zh-CN/USER_GUIDE.md)涵盖三版差异、在线计算、Git Bridge、备份和故障处理。

## 本次变化

- 修复 Web/Desktop 共用侧栏位移规则导致宽屏目录区域空白的问题；统一 Files/Recent/Extensions 折叠箭头、标签栏按钮对齐和深色选中态。
- 白色与淡绿工作台，统一弹窗焦点和键盘操作、文件菜单定位、窄屏上下文栏与分栏目录定位。
- Native Workspace 新建、编辑、保存和文件操作；Desktop 原生 Git 和本地 Jupyter 生命周期管理。
- Generic Jupyter、JupyterHub、BinderHub 连接、固定 Revision 信任与脱敏诊断。
- 按当前运行版本显示首次使用与计算提示；Git 页面明确 Bridge 的启动目录和用途。
- 新本地 Web 包包含已编译应用、只监听本机的启动器、可选 Git Bridge 与中英文说明。
- 中英文 README 和完整用户手册分开维护，默认中文；更新真实 Web/Desktop 快照。
- Skill 附带维护协议、模板、锁文件和版本化 JSON 校验；保留可移植 Markdown 与 Workspace Schema v1。

## 发行与限制

此版本从 GitHub 直接分发，不要求应用商店资格。**没有 Apple Developer ID 公证或 Windows 受信任发布者签名**，首次打开可能出现系统提示。Updater 仍使用应用内置公钥验签；`SHA256SUMS` 和 `release-manifest.json` 标识版本、Tag、commit、发行渠道与所有下载资产。

Git 支持本地 Status/Diff/Stage/Commit/History；Push/Pull、Clone、分支和凭据由外部 Git 客户端处理。在线 HTTPS 页面需要兼容的 HTTPS Jupyter/CORS/WebSocket，公共 Binder 不保证容量。基础 Python 环境不自动安装知识库依赖或完整 ML/GPU 栈。

本机 macOS Apple Silicon 已进行实际 Workspace/Jupyter 与侧栏走查；Windows/Linux/Intel macOS 的构建验证不能等同干净机器安装验收。公共 Binder 完整执行和跨版本自动升级仍是验证债务。门禁与回滚见[发布矩阵](../RELEASE_MATRIX.md)，具体实测见[候选验证](../STABLE_CANDIDATE_VERIFICATION.md)。
