# TensorNote v1.14.0

Project Experiments opened from a pinned GitHub commit now offer a reproducible Binder entry point. TensorNote builds the URL only from the resolved owner, repository and full 40-character commit SHA, and opens the referenced notebook directly when one is present.

The page checks declared Binder environment files first. A compatible repository shows clear notes about initial build time, temporary resource limits and non-persistent output. An incompatible repository remains fully readable and points to Desktop, cloning and configuration guidance. Links never contain tokens, Compute Profiles or execution permissions.
