# TensorNote v1.6.3

[中文](v1.6.3.md) · English

Fix embedded README HTML appearing as source text across online Web, local Web and Desktop.

- Render HTML banners, centered headings, badges and image dimensions.
- Resolve relative HTML images through the Workspace Provider.
- Remove scripts, event handlers, unsafe URLs, forms and custom CSS; keep fenced HTML as literal code.
- Preserve Markdown, math, lab cards and Workspace Schema v1 compatibility.

Existing validation passed: 184 tests, lint, type checks, production builds, Static boundary checks, 3 performance tests and production dependency audit. The macOS app built successfully; the Happy-LLM README was visually verified in local Web. Release CI performs packaging and release validation without repeating local tests for the version bump.

Download the desktop package for your system, or `TensorNote-local-web-1.6.3.tar.gz` (Node.js 22+, extract and run `node start.mjs`). [Online Web](https://aaronchou313.github.io/tensornote/) · [User guide](../en/USER_GUIDE.md). Save notes and quit the previous desktop app before updating. No workspace migration is needed.

GitHub community distribution remains unchanged: no Apple Developer ID notarization or trusted Windows publisher signing; updater signatures remain required. See [v1.6.2](v1.6.2.en.md) for other boundaries and limitations.
