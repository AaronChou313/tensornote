# TensorNote v2.1.3

此版本增加当前单篇笔记的 PDF 导出，Web 与 Desktop 使用同一套可打印文档。

## 单篇笔记导出 PDF

- 当前笔记顶部工具栏新增“导出 PDF”入口；
- 打印内容使用独立 Print View，不包含 Files、Tabs、工具栏、按钮或 SidePanel；
- 正文沿用现有 MarkdownRenderer，保留 KaTeX、Mermaid、图片、表格、Callout 和代码高亮；
- Derivation Sidecar 在原触发位置展开为完整“补充推导”；
- Jupyter Sidecar 在原触发位置展开 Cell 标题与 Python 代码；
- 导出不会执行 Python、改变 Kernel 状态或写入运行结果；
- 白底黑字打印样式限制宽媒体溢出，并尽量避免公式、图片、表格与短代码块跨页切断。

在浏览器或桌面应用中打开一篇笔记，点击顶部打印图标，然后在系统打印窗口选择“保存为 PDF”。如不需要浏览器自动添加的日期、网址和页码，可在打印设置中关闭“页眉和页脚”。

本版本只支持当前单篇笔记，不提供整个知识库或批量导出。GitHub 社区桌面包仍可能显示操作系统的未认证开发者提示；现有 Updater 验签体系保持不变。
