# TensorNote v0.9.0 — Distribution & Hardening

发布日期：2026-08-31

v0.9.0 让 TensorNote 从持续扩展功能的 Knowledge IDE 进入可迁移、可恢复、可分发并能承受大 Workspace 的稳定候选阶段。

## Workbench 与 Authoring

- 统一侧栏控制、Workspace 切换和 View/Note 路由状态。
- Heading 空行与多行转换、图标格式工具栏、正文与 Frontmatter Properties 分离。
- 切换 Workspace 会检查全部 Dirty Editor 与 Lab，并清理 Provider、Compute、Git 和临时 UI 状态。

## Compatibility & Migration

- 无版本 Workspace Manifest 在内存中迁移为 Schema v1。
- 未来 Schema 保持 Markdown 阅读，同时自动关闭写入、Git 与执行。
- App、Workspace、Extension 与 Git 持久设置具备版本、旧键迁移和无效值清洗。
- Extension Manifest 支持 API v1 协商；未来 API 不会被旧 Runtime 静默加载。

## Recovery

- Dirty Markdown 草稿防抖写入 IndexedDB，并提供 localStorage 降级。
- 恢复、丢弃、保存和 Reload 都有明确行为；恢复不会静默覆盖文件。
- 恢复快照保留文件基线，外部修改仍触发冲突。
- React 渲染崩溃进入恢复页，诊断不包含文档或 Secret。

## Distribution

- 正式支持 Static、Local 与 Self-hosted Web Runtime。
- 提供 Hash Router Static Build、可选 PWA、手动 GitHub Pages Workflow、Docker、Compose 与 Nginx 配置。
- Static/Self-hosted 不显示 Local Git Bridge；未实现的 Server Workspace 不会被宣传为可用。

## Performance & Testing

- Workspace 加载采用受限并发与文件指纹缓存。
- Knowledge Search 预计算字段，文件树按 200 项分批渲染。
- Home、AppShell、Built-in Workspace、Workspace Views、NoteEditor、Jupyter 与重型图形依赖按需加载。
- 自动回归覆盖 10,000 笔记、超过 2MB Markdown、1,000 Asset 列表、Schema/Settings/Extension 迁移和恢复边界。
- 发布候选通过全量 Vitest、ESLint、Local/Static TypeScript + Vite Build、PWA 产物、Dependency Audit、UI detector、浏览器明暗/桌面/窄屏/路由验收和 `git diff --check`。

## 已知边界

- 不包含 Tauri Desktop 安装包或 Server-mounted Workspace。
- 不包含在线插件市场、Git Push/Pull、远程认证、Branch 写操作或冲突合并器。
- PWA 离线只覆盖应用 Shell 与已访问的同源构建资源，不缓存任意远程知识库或计算响应。
