# TensorNote v0.0.1

TensorNote 的首个可发布版本：一个本地优先、Markdown 优先的可执行 AI 学习知识库。

## 主要内容

- 35 篇 V1 深度学习、Transformer、ViT 与 CLIP 学习笔记。
- Markdown 目录、路由、全文搜索、KaTeX、Mermaid 和 Callout。
- 基于本机 Jupyter Server 的可执行 Python Lab。
- PyTorch Self-Attention 七步实验与 Attention Heatmap。
- 学习进度、本地主题偏好和明暗主题。
- Conda、`venv`、`uv`、Jupyter、Kernel、Token/CORS 的完整配置手册。
- TensorNote 品牌 Logo 与响应式界面。

## 本次发布前修复

- 修复明亮主题下代码文字与代码框背景对比度过低的问题。
- 为明亮和暗色主题提供独立的代码与语法高亮色板。
- 修复 Mermaid 图和 Python Lab 卡片被错误包进代码框的问题。
- 增加 Markdown 特殊代码块的渲染回归测试。

## 启动

完整说明见 `docs/ENVIRONMENT_SETUP.md`。首次安装依赖后，每次使用需要启动本地 Jupyter Server 和 TensorNote 前端；仅阅读 Markdown 时只需启动前端。
