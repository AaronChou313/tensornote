# TensorNote v1.7.0

Project Experiment Preview A publishes the format baseline for multi-file Python, notebooks, training steps, isolated environments, and artifacts.

- Adds the Manifest v1 specification and JSON Schema.
- Adds minimal valid and path-escape fixtures.
- Defines Desktop, Local Web, and Pages capability boundaries and security invariants.
- Provides the Happy-LLM chapter 5–6 migration map and the complete phased plan.
- This release only publishes declarations and contracts; it does not read, install, or execute Project Experiments.

Compatibility: Workspace Schema v1, Provider API v1, and existing Inline Labs are unchanged. Community desktop packages remain unsigned by platform publisher certificates; updater artifacts remain cryptographically signed.
