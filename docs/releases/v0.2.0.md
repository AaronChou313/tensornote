# TensorNote v0.2.0 — Authoring

TensorNote 从只读 Workspace 进入日常 Markdown 创作阶段。所有编辑结果继续直接保存为普通文件，不引入内容数据库或专有格式。

## Markdown 创作

- Reading、Editing、Split 三种模式。
- CodeMirror 6 Markdown 编辑器、Undo / Redo 和 `Ctrl/Cmd + S`。
- Dirty State、页面离开保护与保存状态反馈。
- 基于文件修改时间和大小的外部变化检测、乐观锁保存与冲突保护。
- Frontmatter Properties 面板，保留未知属性并写回 Markdown。

## 文件与资源

- 本地 Provider 升级为读写模式。
- 新建笔记、空文件夹、重命名、移动、删除和复制 Markdown 文档。
- 支持打开空目录并创建第一篇笔记。
- 粘贴图片、拖放文件、Asset 文件选择；资源自动写入 `assets.root` 并插入相对链接。

## Executable Lab

- Python Lab 中的代码修改可以通过 `Save to note` 精确写回原 executable Fence。
- Lab 写回同样使用冲突保护，不会静默覆盖外部文件变化。

## 设计与兼容

- Authoring Toolbar、编辑器、Split Preview、Properties 和文件操作对话框延续淡绿色、柔和圆润的视觉系统。
- 深色与浅色编辑器均使用独立高对比配色。
- 内置与 GitHub Provider 继续只读，UI 不显示写入入口。
- 保留新版正方形/长方形 TensorNote Logo 与首页文案。

## 验证

- `pnpm test`
- `pnpm lint`
- `pnpm build`
- 浏览器验收 Reading / Editing / Split、Properties、Dirty State、文件对话框、Lab 回写入口和只读 Provider 隔离。
