# TensorNote v1.9.0

Project Experiments are now discoverable and inspectable. A `tensornote-experiment` reference renders as an Experiment Card, the sidebar and command palette expose an Experiments entry, and the dedicated page includes Environment, Steps, Files, Run, and Artifacts tabs.

The interface reports the active Desktop, Local Web, or Online Web boundary together with Workspace execution, GitHub revision trust, and manifest diagnostics. This release does not install dependencies or execute scripts; the Run tab explains the upcoming capability, while existing Inline Labs and Markdown reading and editing remain compatible.
