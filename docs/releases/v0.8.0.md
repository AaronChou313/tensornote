# TensorNote v0.8.0 — Git & Sync

发布日期：2026-08-30

v0.8.0 为 Local Workspace 增加可选的本地 Git 工作台，在不改变 Markdown-first 数据边界的前提下，把 Status、Diff、History、Staging、Commit 与 Branch Info 放进 TensorNote。

## 新增

- `/git` 工作台，显示当前 Branch、Upstream、Ahead / Behind、Staged 与 Working tree 状态。
- 逐文件 Worktree / Staged 文本 Diff，支持新增、修改、删除、重命名、未跟踪与冲突状态。
- 文件级 Stage / Unstage 与本地 Commit；只有已暂存内容会进入提交。
- 最近 40 条本地提交历史，显示 Author、时间、Subject 与短 Hash。
- 编辑器未保存草稿提示，明确未落盘内容不会进入 Git。
- `pnpm git:bridge` 本地 companion，启动时固定仓库根目录。
- 离线、空仓库、干净工作树、无文本 Diff、错误与窄屏状态。

## 安全边界

- Bridge 只绑定 `127.0.0.1`，默认只允许 TensorNote 的 localhost Origin。
- 浏览器客户端拒绝非本机 Bridge URL。
- Git 使用 `execFile` 参数数组运行，不经过 Shell；文件操作拒绝绝对路径和 `..` 越界。
- Bridge Commit 禁用 Repository Hook 与自动 GPG 签名，避免网页操作触发仓库脚本或交互式签名。
- 不提供任意 Git 参数、任意工作目录、凭据访问、Push、Pull、Fetch、OAuth 或私有仓库认证。
- Sync 仍然完全可选；普通阅读、编辑和 Jupyter 不依赖 Git Bridge。

## 测试与验证

- Git 协议解析覆盖 Branch、Ahead / Behind、Staged、Working tree、Rename 与 Untracked。
- 临时真实仓库覆盖 Init、Status、Stage、Commit、History 与提交后 Clean 状态。
- 客户端覆盖 URL 编码、Bridge 错误、离线状态和 Loopback 限制。
- 通过全量 Vitest、ESLint、TypeScript 与 Vite 生产构建。
- 通过离线/在线、浅色/深色、桌面/390px 窄屏和真实仓库浏览器回归。

完整安装、操作、安全与故障排查见 [Local Git 使用说明](../GIT_AND_SYNC.md)。

## 当前限制

- 只支持浏览器打开的 Local Workspace；Bundled 与 GitHub 阅读来源不连接本地 Git。
- Bridge 必须在独立终端显式启动，并且必须指向仓库根目录。
- 不提供 Clone、Push、Pull、Fetch、Branch 操作、Merge、Rebase、Reset、冲突编辑器或远程认证。
- Diff 仅用于文本预览；二进制内容不展开，超长补丁在 UI 中截断。
