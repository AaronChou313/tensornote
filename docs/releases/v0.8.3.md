# TensorNote v0.8.3 — Recovery

发布日期：2026-08-30

v0.8.3 是通向 v0.9.0 的源码阶段里程碑，补齐非破坏式 Autosave Recovery、外部冲突延续保护与 Crash Recovery。本阶段提交并推送代码，但不创建 GitHub Release 或 Tag。

## 改进

- Dirty Markdown 草稿按 Workspace 与文档路径隔离，750ms 防抖写入 IndexedDB，并提供 localStorage 降级路径。
- 重新打开笔记时由用户明确恢复或丢弃；恢复数据不会自动覆盖 Workspace 文件。
- 快照携带文件基线，恢复后的保存仍检查外部修改冲突。
- 成功保存、从磁盘 Reload 或主动丢弃会删除快照；过期快照自动清理。
- 顶层 Recovery Boundary 捕获渲染崩溃，提供重新加载、返回启动页与复制最小诊断。
- 崩溃诊断不包含 Markdown、Token、Secret 或 Git 凭据。

## 验证与发布边界

- 回归覆盖草稿隔离、写入、清除、过期和崩溃诊断隐私边界。
- 阶段候选通过全量 Vitest、ESLint、TypeScript/Vite 构建和 `git diff --check`。
- 本阶段创建 Git commit 并推送 `main`，但不创建 GitHub Release 或 Tag。
