# TensorNote v0.9.5 — Pane Controls Polish

源码阶段日期：2026-08-31

v0.9.5 专注于阅读编辑区操作栏的视觉与交互手感。本阶段提交并推送源码，不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 标签与关闭操作

- 标签改为标题和关闭按钮共用的紧凑圆角单元，选中态使用淡绿色表面而不是零散的边框与下划线。
- 标签关闭按钮拥有独立的圆角命中区、悬停色、按下反馈和键盘焦点环。
- 窗格关闭按钮与标签关闭分离为右侧独立危险操作，采用一致的尺寸、圆角和红色悬停提示。

## 历史导航

- 后退和前进按钮扩大至可舒适点击的成对控件。
- 为空历史增加禁用态；可用按钮提供淡绿色悬停、按下缩放和键盘焦点反馈。
