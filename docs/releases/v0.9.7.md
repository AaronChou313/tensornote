# TensorNote v0.9.7 — Executable Lab Authoring

源码阶段日期：2026-08-31

v0.9.7 完成进入 v1.0.0 收尾前的编辑器与文件侧栏体验修复。本阶段提交并推送源码，不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 编辑器工具栏

- 所有 Markdown 快捷操作优先直接显示；只有空间不足的尾部操作才会进入下箭头溢出菜单。
- 文本样式、代码语言和“实验”入口始终保留，分栏或窄屏时仍可稳定操作。
- 移除重复的普通引用快捷入口，保留更适合知识笔记的 Callout；普通 Blockquote 仍可从命令面板调用。

## 可执行实验

- 新增烧瓶“实验”按钮和组件化插入窗口，不再要求用户手写 executable Fence 元数据。
- 支持设置实验标识、运行级别和多个顺序 Cell；选中的 Python 代码会自动成为第一个 Cell。
- 生成内容保持为可移植 Markdown，并继续兼容阅读视图实验卡、共享 Kernel 和 Scratch Lab 写回。

## 文件侧栏

- FILES 的新建笔记、新建文件夹与折叠箭头使用独立命中区，不再相互覆盖。

## 验收

- `pnpm test`、`pnpm lint`、`pnpm build`、`git diff --check` 通过。
