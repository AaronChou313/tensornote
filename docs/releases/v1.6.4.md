# TensorNote v1.6.4

中文（默认） · [English](v1.6.4.en.md)

本次 Patch 修复远程知识库刷新和文件导航，并移除暂不成熟的内置 Focus Mode。在线 Web、本地 Web与桌面版共享这些修改。

- “最近打开”支持单条移除和全部清空；只删除本机快捷记录，不删除知识库或信任设置。
- 未固定 Revision 的 GitHub 链接重新打开时绕过浏览器缓存并解析分支最新提交；完整 commit 链接仍保持固定。
- Files 严格保留 `content.root` 内的真实文件系统层级与目录名，不再被 Frontmatter `section` 或 `overview.md` 重命名。
- 每一级先显示文件夹，再按真实目录名和文件名自然排序，例如 `chapter2` 位于 `chapter10` 前。
- 移除内置 Focus Mode 及其旧设置；Extension API 和本地扩展管理器继续保留。

相关修改已分别通过完整检查，共 187 项测试、Lint、类型检查和生产构建。发行流水线继续执行版本一致性检查及全平台构建。

GitHub 社区包仍没有 Apple Developer ID 公证或 Windows 受信发布者签名；Updater 强制验签。其他功能边界见 [v1.6.3](v1.6.3.md)。
