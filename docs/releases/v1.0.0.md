# TensorNote v1.0.0 — Stable Platform

TensorNote v1.0.0 是首个稳定平台版本。它不再扩张功能面，而是把 v0.1–v0.9 已完成的本地 Markdown Workspace、知识系统、Jupyter Compute、Workbench、扩展、结构化知识、Local Git、恢复与分发能力收敛为可长期兼容的基线。

## 稳定契约

- Workspace Repository Schema v1。
- WorkspaceProvider API v1。
- ComputeProvider API v1。
- Extension API v1。
- Executable Markdown Syntax v1。
- Settings / Secret Model v1。

这些契约统一从 `src/platform/index.ts` 导出。v1.x 可以加入向后兼容的可选能力；破坏性变化只进入新的主版本。完整规则见 [Platform Contracts](../PLATFORM_CONTRACTS.md)。

## 首发能力

- Local：打开普通 Markdown 文件夹，编辑正文和 Properties，管理文件与 Assets，保存并可选连接本地 Git Bridge。
- Knowledge：全文搜索、WikiLink、Backlinks、Outline、局部图谱、标签与结构化 Frontmatter 查询。
- Workbench：独立 Pane/Tab/History、分栏、焦点上下文、设置弹窗、命令面板和响应式编辑工具栏。
- Compute：多个 Profile、Workspace 显式执行授权、GitHub Revision 信任、多 Cell Lab、Scratch Lab、诊断和 Kernel 生命周期控制。
- Distribution：Local、Static 与 Self-hosted Web Runtime、可选 PWA、GitHub Pages Workflow 和 Docker/Nginx。
- Recovery：浏览器草稿恢复、文件冲突保护、未来 Schema 只读降级和应用级恢复界面。
- Agent Interface：可安装的 `tensornote-knowledge-workspace` Skill、知识撰写/配置/运行规范、完整 Workspace/笔记/Lab 模板与确定性校验器。

## 数据与安全

- Markdown、Assets 和 `tensornote.yaml` 是唯一可移植知识源。
- 浏览器偏好与恢复草稿不写入 Workspace；Jupyter Token 和扩展 Secret 只保留在会话存储或运行时内存。
- Workspace 必须通过 Manifest 或当前设备设置显式允许执行；GitHub Workspace 还必须信任固定到当前 Commit SHA 的 Revision。
- TensorNote 不静默安装 Python 环境，不执行任意 Git 命令，不提供远程 Git 凭据管理。

## Release Gate

源码候选已经通过：

- 30 个 Vitest 文件、102 项测试、ESLint、TypeScript/Vite Local Build 与 `git diff --check`。
- 3 项性能回归预算，覆盖 1,000/10,000 笔记、超过 2MB Markdown 与 1,000 Assets。
- `pnpm audit --prod --audit-level high`，无已知漏洞。
- Static `/tensornote/` Base Path Build 与基于产品版本的 PWA Cache 更新策略。
- Home、Workspace、Note、独立 Pane、Settings、Lab、Command Palette 与明暗主题关键浏览器流程。

当前候选机器未安装 Docker，因此未运行 Compose/镜像验证；有 Docker 的正式发布环境仍应执行文档中的容器门。
