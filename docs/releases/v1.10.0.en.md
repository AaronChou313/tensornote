# TensorNote v1.10.0

Desktop Project Experiments now provide an auditable environment preparation flow. The Experiment page discovers local Python and environment tools, resolves inherited dependency files, and previews the target, steps, sizes, and SHA-256 digests. An isolated environment is created and dependencies are installed only after the confirmation phrase is entered.

Plans are bound to the authorized Workspace, Experiment Manifest, and dependency contents. Expired plans or changed manifests and dependency files are rejected and require a fresh confirmation. Installation logs are visible, operations can be cancelled, partial directories are cleaned, and the runtime assistant can safely remove TensorNote-managed environments that are not in use by Jupyter.
