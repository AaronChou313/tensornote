# TensorNote v1.6.0

[中文（默认）](v1.6.0.md) · English

GitHub community distribution: Online Web, a standalone Local Web package, Desktop installers and the matching agent skill. Publication time, commit and assets are recorded in the [GitHub Release](https://github.com/AaronChou313/tensornote/releases/tag/v1.6.0).

## Getting started

- [Online](https://aaronchou313.github.io/tensornote/): open examples or a public GitHub knowledge repository.
- Local Web: extract `TensorNote-local-web-1.6.0.tar.gz`, install Node.js 22+, run `node start.mjs`. No frontend dependency installation is required.
- Desktop: install the package for your OS/architecture and open a local folder. Configure Jupyter only when you need experiments.
- Agents: extract `TensorNote-agent-skill-1.6.0.tar.gz` and give the complete skill and target knowledge folder to your agent.
- The [English user guide](../en/USER_GUIDE.md) covers edition differences, remote compute, Git Bridge, backups and troubleshooting.

## Changes

- Fix shared Web/Desktop sidebar transform conflicts that left a blank directory area on wide screens; align section arrows and tab controls, and improve dark-mode selection.
- White and pale-green workbench, shared dialog focus and keyboard behavior, stable file menus, narrow-screen context drawers and pane-scoped outlines.
- Native workspace authoring, Desktop system Git and local Jupyter lifecycle management.
- Generic Jupyter, JupyterHub and BinderHub connectors with revision trust and redacted diagnostics.
- Contextual edition-specific first-use and compute help; clearer Git Bridge setup instructions.
- A new Local Web archive includes the compiled app, loopback-only launcher, optional Git Bridge and bilingual manuals.
- Separate Chinese-default and English READMEs and complete user guides, with fresh real Web/Desktop screenshots.
- The agent skill includes maintenance rules, templates, a lockfile and versioned JSON validation while preserving Markdown portability and Workspace Schema v1.

## Distribution and limits

Distributed directly on GitHub, without app-store enrollment. **No Apple Developer ID notarization or trusted Windows publisher signature is provided.** Your OS may warn on first launch. Updater verification still uses the embedded public key. `SHA256SUMS` and `release-manifest.json` identify the version, tag, commit, distribution policy and download assets.

Git provides local status/diff/stage/commit/history; use a Git client for Push/Pull, Clone, branches and authentication. HTTPS web pages require compatible HTTPS Jupyter, CORS and WebSockets. Public Binder capacity is not guaranteed. Basic Python environments do not automatically install workspace dependencies or a full ML/GPU stack.

Workspace/Jupyter and sidebar workflows have been exercised on local Apple Silicon macOS. Successful Windows/Linux/Intel macOS builds do not constitute clean-machine installation testing. Public Binder execution and a real cross-version updater cycle remain verification debt. See the [release matrix](../RELEASE_MATRIX.md) and [candidate evidence](../STABLE_CANDIDATE_VERIFICATION.md) (Chinese) for gates and rollback.
