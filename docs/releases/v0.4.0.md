# TensorNote v0.4.0 — Compute Platform

v0.4.0 把原有单一 Jupyter 连接重构为可扩展 Compute Layer，并补齐多环境、Session 生命周期、完整 Lab 控制、Scratch Lab、环境检测和连接诊断。

## 新功能

- 新增 `ComputeProvider`、`ComputeSession` 与 `ComputeRuntime` 抽象；Jupyter 成为首个 Provider。
- 新增多 Compute Profile，可从 Local Python、Laptop GPU、Lab RTX4090、Remote Server 与 Jetson 模板创建。
- Profile 支持 Per note、Per workspace、Manual 三种 Session Scope。
- Lab 新增 Run Above、Run Below、Restart & Run All；保留 Run、Run All、Interrupt、Restart、Clear Outputs 与 Save to note。
- 新增 Scratch Lab：临时代码默认不写入 Markdown，仅在用户点击 `Insert into note` 时生成 executable Fence。
- `tensornote.yaml` 可声明 `environment.files`；同时发现根目录常用 Python 环境文件，只检测、从不自动安装。
- 新增 Browser、Server、Authentication、CORS、Kernel、WebSocket 六项连接诊断。

## 界面

- Compute 设置改为 Profile Rail + 分区配置的圆润双栏面板，与现有淡绿色、简约柔和设计系统一致。
- 顶栏直接显示当前 Profile 和 Kernel 状态，并提供 Scratch 快捷入口。
- Lab 工具栏与 Cell 级执行控制重新整理，支持窄屏布局。
- 明暗主题下 CodeMirror 的背景、默认文字、行号和活动行都绑定主题变量，修复浅色模式可读性问题。

## 安全与兼容

- Jupyter Token 继续只保存在当前浏览器会话，并在诊断错误中脱敏。
- GitHub Workspace 仍需信任固定 Revision 才能执行。
- 老版本保存的 Jupyter URL 与 Kernel Name 会迁移为默认 `Local Python` Profile。
- Profile、连接或 Scope 改变时关闭不兼容 Kernel；Workspace 关闭时清理所有 Scope。
- 环境文件声明不是安装授权，TensorNote 不调用 pip、Conda 或 uv。
