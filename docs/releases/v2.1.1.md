# TensorNote v2.1.1

此补丁版本完善阅读、文件身份与 Sidecar 写作体验：

- 阅读模式移除旧 Knowledge Panel 留下的 286px 空列，正文扩展到舒适的 900px 上限；
- 每篇笔记在当前 Workspace Session 中独立保存滚动位置，显式标题跳转优先；
- 路径决定文件身份，显式 Frontmatter ID 决定知识语义身份；不同目录的同名 Markdown 可正常打开；
- Files 严格保持文件系统层级和文件名排序；Overview 只使用根目录 `OVERVIEW.md` 或 `README.md`；
- “侧栏内容”支持可视化新增、编辑、删除 Derivation 与 Jupyter Sidecar，包含 Markdown 预览、Python Cell 编排和格式诊断；
- Skill 与 Validator 同步描述并检查上述规则。

本开发任务不修改 Desktop 自动更新与签名体系。
