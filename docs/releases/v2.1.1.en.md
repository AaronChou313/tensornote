# TensorNote v2.1.1

This patch improves reading, file identity, and Sidecar authoring:

- removes the obsolete 286px Knowledge Panel column and raises the comfortable note width to 900px;
- restores an independent in-session scroll position per note, with explicit heading navigation taking priority;
- uses paths for file identity and explicit Frontmatter IDs for semantic identity, allowing duplicate Markdown filenames across directories;
- preserves filesystem hierarchy and filenames in Files, and limits Overview selection to root `OVERVIEW.md` or `README.md`;
- adds visual create, edit, and delete flows for Derivation and Jupyter Sidecars, with Markdown preview, Python Cell ordering, and diagnostics;
- synchronizes the bundled Skill and Validator with the application behavior.

This development task does not change Desktop updater or signing infrastructure.
