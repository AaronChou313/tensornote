# TensorNote v0.7.0 — Structured Knowledge

v0.7.0 为 Markdown Workspace 增加 Structured Knowledge：使用现有 YAML Frontmatter 组织笔记，而不是把内容迁移到 SQL 或专有数据库。

## Database views

- 新增 `/database` 入口，以当前 Workspace 的 Frontmatter 属性浏览文档。
- 同一结果可切换 Table、Card、List 三种视图；每个条目始终链接回原始 Markdown 笔记。
- 查询和视图状态保存在 `q`、`view` URL 参数中，可保存书签或分享给有权访问同一 Workspace 的协作者。

## PropertyIndex and queries

- 新增运行时 `PropertyIndex`，从 `Note.properties` 生成文档行、字段类型、值预览和查询结果。
- 支持 `=`、`!=` 与 `AND`；属性键不区分大小写。
- 查询支持字符串、数字、布尔值、`null` 和数组成员匹配。字符串可使用单引号或双引号，并支持必要的反斜杠转义。
- 保存或重新打开 Workspace 后，索引从源 Markdown 重建；Database 不写回属性，也不维护第二份内容数据。

## Boundaries

- 当前不支持 `OR`、括号、范围比较、模糊匹配、排序、分组、聚合、保存视图或数据库式编辑。
- 查询在浏览器本地的运行时索引执行，不执行 SQL、YAML、Markdown 或用户脚本。
- 本地和远程 Workspace 仍分别遵守既有的浏览器文件权限与只读边界。

完整 Frontmatter 模板、查询规则、刷新步骤和限制见 [Structured Knowledge 使用指南](../STRUCTURED_KNOWLEDGE.md)。
