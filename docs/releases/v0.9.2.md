# TensorNote v0.9.2 — Workbench Interaction Refinement

源码阶段日期：2026-08-31

v0.9.2 聚焦工作台的可预测性和视觉收敛：可以独立操作每一个 Pane，实验始终从正确笔记打开，导航减少重复入口。此版本会提交并推送源码，但不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## Pane 与 Lab 可靠性

- Pane 可分别关闭；主 Pane 关闭时自动提升另一 Pane，关闭最后一个 Pane 显示可恢复的空工作台。
- Split 不复制笔记，两个 Pane 分别维护自己的标签、历史和活动内容。
- 从笔记打开 Lab 会关闭右侧上下文栏；Lab 实例按 Workspace、笔记和 Lab ID 联合定位，防止跨笔记显示陈旧实验。

## 信息架构与视觉

- 收起侧栏后，恢复按钮固定在顶栏左侧；命令与 Scratch 收敛为图标，重复的顶栏搜索框移除。
- Workspace popover 移除重复 Overview；来源类型和读写权限移动至顶部标签，Recent Files 可折叠，底部来源卡片移除。
- 浅色模式改为白色页面与内容主体，淡绿只用于控件、选中、悬浮和焦点；深色模式使用一致的中性深色表面。

## 验收

- 单元回归覆盖 Pane 提升、最后 Pane 关闭以及 Lab 打开时收起右栏。
- 浏览器验收覆盖空白 Split、双笔记独立 Pane、任意 Pane 关闭、LabDrawer、收起侧栏的左侧恢复入口和白色主体样式。
