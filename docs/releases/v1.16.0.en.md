# TensorNote v1.16.0

Project Experiment is now a stable feature. Readers can inspect environments, steps, files, run state and artifacts from a note card or the Experiments navigation. Desktop supports reviewed environment preparation, multi-file Python, notebooks, torchrun, logs, cancellation, recovery and artifact location. Local Web runs the Jupyter-compatible subset after path mapping succeeds. GitHub Pages remains safe for reading and offers a pinned-revision Binder handoff.

This release completes Chinese-first and English user and author documentation. The README follows the download, open, configure, run and recovery journey, including guidance for missing Python, no network, no GPU, low disk space, dependency conflicts, cancellation and interrupted runs. The knowledge-workspace Skill, templates and deterministic validator match Manifest v1. Happy-LLM chapters 5 and 6 are the multi-script pilot with grouped dependencies, CPU smoke presets, training entries and declared artifacts.

Execution still requires host capability, Workspace authorization, trust in a full GitHub commit SHA, plan review and user confirmation. Pages cannot access local files or supply compute. Binder supports public repositories only, uses temporary non-persistent environments and may queue. Git Bridge handles Git only; Local Web and Pages do not create native environments. GitHub community desktop packages are not notarized with Apple Developer ID or signed by a trusted Windows publisher; updater artifacts remain project-signed.
