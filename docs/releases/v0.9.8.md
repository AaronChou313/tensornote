# TensorNote v0.9.8 — Workspace Execution Permission

源码阶段日期：2026-08-31

v0.9.8 为 Compute 设置加入 Workspace 级代码执行开关。本阶段提交并推送源码，不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 执行授权

- “设置 → 计算与 Jupyter”新增“允许当前 Workspace 执行代码”开关，修改立即生效并自动保存。
- 授权按 Workspace 保存在当前浏览器，可以覆盖 `tensornote.yaml` 的默认值，但不会静默修改用户文件。
- Lab 权限提示现在可直接打开 Compute 设置；设置作为弹窗覆盖在实验上方，关闭后仍保留原实验与未保存代码。

## 安全边界

- GitHub Workspace 即使开启执行，仍需信任固定到当前 Commit 的 Revision。
- 使用未来版本 manifest 的 Workspace 不能通过开关绕过兼容性保护。
- 关闭开关会立即禁止向当前 Kernel 发送新的代码。

## 验收

- Workspace 执行策略覆盖 manifest 默认、用户覆盖、未来 schema 与远程信任测试。
- `pnpm test`、`pnpm lint`、`pnpm build`、`git diff --check` 通过。
