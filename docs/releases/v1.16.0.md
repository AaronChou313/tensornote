# TensorNote v1.16.0

Project Experiment 现已作为稳定功能交付。用户可以从笔记卡片或 Experiments 导航查看环境、步骤、文件、运行状态和产物；桌面版支持受控环境准备、多脚本 Python、Notebook、torchrun、日志、取消、恢复和产物定位，本地 Web 支持路径映射通过的 Jupyter 子集，GitHub Pages 可安全阅读并为固定提交提供 Binder 引导。

本版本补齐中文默认、英文对照的用户与作者文档，README 以下载、打开、配置、运行和故障恢复为主线，并明确无 Python、无网络、无 GPU、磁盘不足、依赖冲突、取消及崩溃后的处理方式。知识库 Skill、模板和确定性 Validator 与 Manifest v1 保持同版本；Happy-LLM 第 5～6 章作为多脚本试点，包含分组依赖、CPU smoke、训练入口和声明式产物。

执行仍需平台能力、Workspace 授权、GitHub 完整 commit SHA 信任、计划预览和用户确认。Pages 不会访问本地文件或替用户提供计算资源；Binder 仅适用于公开仓库且环境临时、不持久，公共服务可能排队。Git Bridge 只负责 Git，本地 Web 与 Pages 不创建本机隔离环境。GitHub 社区桌面包没有 Apple Developer ID 公证或 Windows 受信发布者签名，Updater 附件仍使用项目签名。
