# TensorNote v1.2.0 — Native Local Workspace

状态：源码阶段完成；未创建 Git Tag 或 GitHub Release

## 本阶段交付

- Desktop 首页通过系统目录选择器打开或新建本地 Markdown Workspace，不依赖 Chromium File System Access API。
- Rust 只向前端返回 Opaque Workspace ID；所有文件操作限定为已授权根目录内的受检相对路径，并拒绝绝对路径、父级穿越、隐藏/构建目录和 Symlink escape。
- 文本与二进制保存使用原子替换；编辑器沿用 WorkspaceProvider API v1 的修改时间/大小冲突保护和恢复流程。
- 最近目录恢复、目录/Markdown 拖放、`.md` / `.markdown` 文件关联入口，以及 Finder/Explorer Reveal 已接入同一授权模型。
- Desktop Git 工作台直接使用系统 Git，支持 Status、History、Diff、Stage/Unstage 与本地 Commit；不开放任意 Shell、Push、Pull 或凭据操作。Local Web Git Bridge 保持兼容。
- Static Web 的编译期裁剪和产物扫描保证 GitHub Pages 不包含 Tauri、Native Workspace 或 Native Git IPC。

## 当前限制

- 文件监听首版采用受限 `stat` 轮询；可在保持 Provider API 不变的前提下升级为事件 watcher。
- Desktop 需要系统已安装 Git；尚不提供 Git 安装、认证、Push/Pull、Branch 管理或冲突合并器。
- Conda/venv/uv 检测、环境创建、Jupyter Server 一键启停与日志属于 v1.3.0。
- 当前安装资产未签名、公证或发布；本阶段不创建 Tag/Release。

## 验证范围

- Web：全量测试、Lint、Local/Static 生产构建、Static IPC 边界、性能门与生产依赖审计。
- Desktop：Rust fmt/clippy/test、路径与原子写安全测试、真实临时 Git 仓库 Stage/Commit、Tauri release compile 和当前平台 Bundle。
- CI：Linux、macOS、Windows Desktop compile smoke，Web 与容器门保持不变。
