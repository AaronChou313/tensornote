# TensorNote v1.14.0

从 GitHub 固定 commit 打开的 Project Experiment 现在会提供可复现的 Binder 入口。TensorNote 使用当前 Workspace 已解析的 owner、repository 和完整 40 位 commit SHA 构建链接，并在存在 Notebook 时直接打开对应文件。

入口会先检查知识库声明的 Binder 环境文件。配置可用时，界面明确说明首次构建等待、临时资源限制和输出不持久；配置不足时仍保留全部阅读能力，并引导用户下载桌面版、克隆仓库或补充 Binder 配置。链接不包含 Token、Compute Profile 或执行授权。
