# TensorNote v1.11.0

Desktop Project Experiments can now execute structured multi-script `python` and `python-module` jobs. Before execution, TensorNote previews the environment, script SHA-256 digests, argv arrays, steps, and output scopes. A managed Python process starts only after explicit confirmation; manifests cannot supply arbitrary shell command strings.

The Run tab streams bounded logs and per-step state. A failure blocks later steps, and users can cancel, rerun all steps, or continue from the failed step. Job summaries live in application data, running jobs recover as `interrupted` after an abnormal exit, and completed history can be cleared. Declared artifacts can be revealed in the desktop file manager.
