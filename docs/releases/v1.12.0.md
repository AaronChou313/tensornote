# TensorNote v1.12.0

Project Experiment 现已覆盖 Notebook 与分布式训练入口。Notebook Runner 使用受管环境中的 Jupyter 执行源 Notebook，并将结果保存为应用数据目录中的独立副本，原文件保持不变；完成后可从运行记录定位执行副本。

`torchrun` 使用结构化的进程数、节点、Rank、地址、端口与 argv 字段，通过固定环境 Python 启动，不执行 Shell 字符串。桌面版会在运行前显示 CPU、内存、磁盘、GPU 与 CUDA 检测结果；资源明显不足时必须明确选择继续。长任务显示逐步骤状态、最近日志、运行时长与系统唤醒提示。

Manifest v1 新增可选 `downloads` 元数据，用于说明模型或数据来源、大小、缓存路径、许可与 SHA-256；TensorNote 只展示并审查这些信息，不自动下载。
