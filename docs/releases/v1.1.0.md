# TensorNote v1.1.0 — Dual Host Foundation

状态：源码阶段完成；未创建 Git Tag 或 GitHub Release

## 本阶段交付

- 新增统一 HostAdapter 与明确 capability 模型，Web 和 Desktop 继续共享同一个 React 产品核心。
- 新增 Tauri 2 最小桌面宿主、应用图标、版本元数据和 macOS/Windows/Linux 编译门。
- 新增 Desktop/Static 专用构建模式；验证 Static Web 产物不包含 Tauri IPC。
- Desktop 首页根据真实能力隐藏尚不可用的本地目录入口，保留 Built-in/GitHub Workspace 与既有 Jupyter 连接。
- 冻结首阶段安全面：唯一 IPC `platform_info` 无参数且只读，不启用 Shell、文件系统或进程插件。

## 当前限制

- v1.1.0 是架构和构建基础，不是正式桌面安装包 Release。
- 原生本地 Workspace、文件监听与 Native Git 进入 v1.2.0。
- Conda/venv/uv 环境检测、基础环境创建和 Jupyter Server 生命周期进入 v1.3.0。
- 当前平台生成的应用没有签名、公证或自动更新，不建议作为公开下载资产分发。

## 验证范围

- Web：全量测试、Lint、Static Base Path 生产构建、依赖审计与性能门。
- Desktop：Rust fmt/clippy/test、Tauri release compile、当前 macOS `.app` 构建与真实界面主流程。
- CI：Linux、macOS、Windows 的 Desktop compile smoke。
