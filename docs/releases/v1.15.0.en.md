# TensorNote v1.15.0

Knowledge-base agents can now use the same Project Experiment contract as the application. The Skill shipped with each Release adds complete selection, safety and platform review rules, minimal and full manifest templates, and stronger standalone validation for environment inheritance, presets, step graphs, structured arguments, artifacts and read-only download declarations.

The Happy-LLM TensorNote example has completed its first migration. Chapters 5 and 6 retain their original command-line scripts while adding purpose-specific dependency files, CPU-safe checks, single-process and distributed training entries, notebook entries and declared artifacts. Strict Workspace validation reports zero errors and warnings. A manifest never installs, downloads or runs content by itself; execution still requires platform capability, trust, plan review and explicit user confirmation.
