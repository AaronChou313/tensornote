# TensorNote v0.9.4 — Stable Focused Workbench

源码阶段日期：2026-08-31

v0.9.4 收敛阅读编辑区的焦点、路由与实验状态边界。本阶段提交并推送源码，不创建 Git Tag 或 GitHub Release；最近正式 Release 仍为 v0.9.0。

## 稳定的窗格交互

- 焦点切换不再改写页面路由：点击窗格、当前标签或笔记内交互控件不会重新加载显示区、重置滚动位置或产生页面抖动。
- 当前标签被再次点击时是无操作；历史不会重复记录，内容不会重渲染。
- 移除固定标签功能与图标。每个标签均可用自身的关闭按钮关闭，窗格仍可独立关闭。

## 可靠的 Python Lab

- 修复实验卡的状态竞态：此前窗格的鼠标事件会触发路由切换，进而清空刚刚打开的实验；现在实验卡会稳定打开对应笔记与实验。
- 浏览器验收覆盖“初始化与归一化”中的 `Batchnorm Vs Layernorm`：打开实验、点击当前标签后实验仍保持打开。

## 视觉细化

- 阅读内容在单窗格与分栏中均使用居中的白色阅读列。
- 标签提升字重、尺寸、内边距与关闭区的对齐，减少拥挤和文字样式异常。
- Recent Files、Files、Extensions 的可折叠标题使用同一间距体系，避免侧栏基线错位。

- `pnpm lint`、`pnpm build`、`git diff --check` 通过。
