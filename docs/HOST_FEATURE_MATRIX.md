# TensorNote 2.0 Host 能力

| 能力 | Web | Desktop |
| --- | --- | --- |
| 内置与 GitHub Workspace | 是 | 是 |
| 浏览器授权本地目录 | 浏览器支持时 | 不适用 |
| 原生本地目录读写 | 否 | 是 |
| Markdown、WikiLink、Search、Outline | 是 | 是 |
| Derivation/Jupyter Sidecar 阅读 | 是 | 是 |
| 远程 HTTPS Jupyter/JupyterHub/BinderHub | 是 | 是 |
| 发现/创建环境并启动本机 Jupyter | 否 | 是 |
| 应用内 Git 工作台 | 否 | 否 |
| 应用自更新 | 由部署方更新 | 签名 Release 可用 |

Static、Self-hosted 和 Development 是 Web 部署方式，不改变此能力矩阵。
